# Quanto Falta?

[![Ler em inglês](https://img.shields.io/badge/Read%20in-English-blue?style=for-the-badge)](README.en.md)
![Versão beta](https://img.shields.io/badge/status-beta-orange?style=for-the-badge)

**Quanto Falta?** é um site simples para acompanhar a contagem regressiva até uma data especial. Informe o nome do evento, escolha a data e o horário e veja quanto tempo falta em dias, horas, minutos e segundos.

> Esta é uma versão beta. O projeto ainda pode receber ajustes e melhorias.

## Funcionalidades

- Contagem regressiva atualizada em tempo real.
- Opção de informar o nome, a data e o horário de um evento.
- Atalhos para o próximo Natal e Ano-Novo.
- Botão para copiar o resultado e compartilhar.
- Preferências salvas no navegador.
- Layout adaptável para celular e computador, com suporte ao tema claro e escuro.

## Como usar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.
3. Escolha uma data e, se quiser, informe o nome do evento e o horário.
4. Use **Copiar resultado** para compartilhar a contagem.

Não é necessário instalar dependências ou iniciar um servidor para usar o site localmente.
