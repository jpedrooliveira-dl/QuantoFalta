# Quanto Falta? (How Much Time Left?)

[![Ler em português](https://img.shields.io/badge/Ler%20em-Portugu%C3%AAs-green?style=for-the-badge)](README.md)
![Beta version](https://img.shields.io/badge/status-beta-orange?style=for-the-badge)

**Quanto Falta?** is a simple website for counting down to a special date. Enter an event name, choose a date and time, and see the time remaining in days, hours, minutes, and seconds.

> This is a beta version. The project may receive updates and improvements.

## Features

- Live countdown that updates in real time.
- Optional event name, date, and time.
- Shortcuts to the next Christmas and New Year's Day.
- Copy button for sharing the countdown.
- Preferences saved in your browser.
- Responsive layout for mobile and desktop, with light and dark theme support.

## How to use

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Choose a date and, optionally, enter an event name and time.
4. Select **Copiar resultado** (Copy result) to share the countdown.

No dependencies or local server are required to use the website locally.
